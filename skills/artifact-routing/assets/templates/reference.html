In one minute

This page lists every command, option, configuration key, environment variable, file, exit code and error message of Driftwood 2.4.0, an open-source CLI that rotates and compresses log files. It describes facts and does not teach or explain; steps and reasons live in other documents.

Look a name up in the contents, press / to search, or follow an ID such as CMD2. Each row has a permanent ID and a link you can copy. Values were read from the source at commit 9f3c2d1 and checked on 2026-11-01. One item is not verified; see Verification and gaps.

driftwood run

driftwood run [--config PATH] [--dry-run] [--verbose]

Rotates and compresses every Live log whose Trigger fired. A Live log is due when its size is above CFG4 or when the CFG5 time has been reached, whichever comes first. After a Rotation, Generations above CFG2 are deleted.

IDNameMeaningTypeDefaultAllowed valuesSinceSource

Configuration file

Driftwood reads FIL1 in TOML. It looks for the file at OPT1, then at ENV1, then in the current folder. All keys live in the [rotate] table.

IDNameMeaningTypeDefaultAllowed valuesSinceSource
CFG1pathFolder that holds the Live logs.stringnone, requiredExisting folder1.0config/schema.py:10-18
CFG2keepNumber of Generations kept per Live log.integer71 to 3651.0config/schema.py:21-28
CFG3compressCompression applied to each Generation.string"gzip""none", "gzip", "zstd" (zstd since 2.2)1.0config/schema.py:30-39
CFG4max_sizeSize above which a Live log is due.string"50MB"Integer plus KB, MB or GB, from 1KB to 10GB1.0config/schema.py:41-52
CFG5scheduleTime Trigger for a Live log.string"daily""hourly", "daily", "weekly", or a 5-field cron expression (cron since 2.1)1.0config/schema.py:54-70

Rules across keys

  • A Live log is due when CFG4 is exceeded or the CFG5 time is reached, whichever comes first.
  • CFG3 set to "none" keeps Generations uncompressed, with no suffix on FIL4.
  • CFG1 is the only required key.

A complete valid file:

[rotate]
path = "/var/log/app"
keep = 7
compress = "gzip"
max_size = "50MB"
schedule = "daily"

Glossary

One definition per term, each a genus plus a difference. Version 1.0, 2026-11-01.

Archive
The set of compressed Generations kept for one Live log. Related: FIL4, CFG3.
Dry run
A run that reports what it would do and changes no file. Related: OPT7.
Generation
A numbered Archive copy of a Live log. Generation 1 is the newest. Related: FIL4, CFG2.
Live log
A log file that an application still writes to. Related: FIL3.
Lock file
The file .driftwood/lock, which stops two runs from rotating at once. Related: FIL5, ERR4.
Retention
The number of Generations kept per Live log, set by CFG2. Related: CFG2.
Rotation
The act of renaming a Live log to Generation 1 and starting an empty Live log. Related: CMD2.
State file
The JSON file that records the last Rotation time of each Live log. Related: FIL2.
Trigger
A condition that makes a Live log due: size above CFG4, or the CFG5 time reached. Related: CFG4, CFG5.
