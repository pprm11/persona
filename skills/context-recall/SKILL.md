# Context Recall

Resolve the applicable memory sources and access policy from the active environment. Start with the current project's index; open only entries relevant to the request. If insufficient, search other permitted indexes, rules and skills using the user's terms, synonyms and any established glossary. Preserve scope and provenance.

Before using a semantic or remote search adapter, check its data-sharing policy and authorization. Verify drift-prone claims such as branch state, paths, configuration and approval against the current source when feasible. Cite the memory or source and distinguish verified current facts from older or uncertain notes.

If the record is stale, report the discrepancy. Reading it does not authorize a write. Use [context-ingest](../context-ingest/SKILL.md) if installed and authorized; otherwise follow the active memory system’s write procedure.
